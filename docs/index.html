4 · Hints that weren't

Qwen run: about 1 in 6 "benefits" were Qwen refusing

To build the attack, Qwen was asked for benefits of each unsafe action. Sometimes it wrote a warning instead, and that warning was injected as the "hint". Those hints barely moved it; real-looking benefits did.

Refusals are found with a keyword rule (phrases such as "none of", "no benefits", "is dangerous", "should not"), so the split is approximate. The authors had people remove "there are no benefits" answers; this run did not, so the 24.6% headline likely understates the attack.
